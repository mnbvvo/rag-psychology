# 真实模型阶梯 · 手动执行完整流程（c1/c5/c10/c20）

> 适用：rag-psychology 并发验收方案 §9.1「真实模型阶梯」由人工自行执行。
> 每档要求：≥10 分钟持续真实模型问答（50% SSE + 50% 同步），判定对照方案 §9.2 门槛。
> 编写：2026-09-04。执行环境：cmd（conda juliy）。预计总耗时 ≈ 45 分钟。

## 0. 一次性前置（跑之前必须完成，缺一不可）

### 0.1 额度必须切换为「付费模式」
> ⚠️ 实测教训（09-04）：**所有真实阶梯在「仅免费额度」模式下必然中途 403 作废**——
> 10 并发 10 分钟会把免费额度几分钟内打光（deepseek-v3.2、glm-5.1 均已验证）。
- 到阿里云 MaaS 控制台（对应实例 `llm-dgqzs8xmwtoly0uo` 所属账号）：
  1. 充值（或确认余额 > 0）；
  2. 把模型的「仅使用免费额度 / use free tier only」开关**关闭**；
  3. 确认要测的模型（CHAT_MODEL）已开通付费访问。

### 0.2 `.env` 四项确认（记事本打开 `C:\Users\Thunderobot\Desktop\rag-psychology\.env`）
```
OPENAI_API_BASE    = 对话端点（如 llm-dgqzs8xmwtoly0uo/.../compatible-mode/v1）
CHAT_MODEL         = 要测的模型（如 deepseek-v3.2 / glm-5.1）
EMBEDDING_API_BASE = 向量端点（与对话可同实例）
EMBEDDING_MODEL    = 向量模型，**维度必须 = 1024**（库列 vector(1024)，实测 text-embedding-v4 = 1024 可用）
EMBEDDING_API_KEY  = 向量密钥（可独立于对话 key）
ENABLE_THINKING    = 留空即可（默认 False=不注入思考参数；模型是否思考由上游默认决定）
```

### 0.3 运行配置自检（关键：避免 10 分钟白跑）
```cmd
cd /d C:\Users\Thunderobot\Desktop\rag-psychology
python scripts\check_env.py
```
- 期望输出：`chat  200` + `embed 1024` + `结论：chat 200 + embed 1024，可以开跑`（退出码 0）
- `chat 401` → API key 无效（换 key）
- `chat 403 ... quota` → 仍在免费额度模式（回 0.1）
- `embed` 非 1024 → 向量模型与库列不匹配，不能用于本测试
- 脚本自己按位置找 `.env`，在哪个目录执行都行。**不要手抄成多行 `python -c`**：`\` 续行只在 Git Bash 有效，cmd 的续行符是 `^`，用 `\` 会让 cmd 只把第一行喂给 python，报 `SyntaxError: unexpected EOF while parsing`。

## 7. 常见问题速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动后 curl health 失败 | 服务没起来/窗口关了 | 回第 1 步，看窗口 A 日志 |
| `chat 401 Invalid API-key` | OPENAI_API_KEY 无效 | 换 key（0.3 复测） |
| `chat 403 Free quota exhausted` | 仍免费额度模式 | 充值 + 关 free tier（0.1） |
| 跑档中途成功率暴跌 + 服务端 403 | 额度被打光 | 回 0.1；重跑该档 |
| 服务端刷 `memory 落库失败: 403` | embedding key/额度问题 | 检查 EMBEDDING_API_KEY（0.3 的 embed 行） |
| 换模型后行为未变 | .env 改了没重启服务 | Ctrl+C 重启服务（第 1 步） |
| 启动报已有实例 | 8000 被占 | `netstat -ano | findstr :8000` → taskkill /PID <pid> /F |
